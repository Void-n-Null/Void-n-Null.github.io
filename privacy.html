Privacy Policy

Last updated: October 25, 2026

Personal Assistant is a private app with a single user, its owner. It is not offered to anyone else.

Data it accesses

With the owner's permission, the app has read-only access to Google account data in the owner's own account. It does not modify, send, or delete anything in that account.

How data is used and stored

Data is used only to provide the app's features to the owner. It is processed and stored on systems the owner controls. It is not sold, not shared with third parties, not used for advertising, and not used to train generalized AI or machine learning models.

Google API Services

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time from Google Account permissions.
